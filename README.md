
# 📊 MavenTech CRM Sales Performance Dashboard

An interactive Power BI dashboard for exploring CRM sales performance, monitoring KPIs, and comparing team and product performance.

## 🎯 Project Objectives

- Monitor revenue and sales win rate.
- Analyze quarterly revenue trends.
- Track average deal size and sales-cycle duration.
- Explore deal-stage distribution.
- Compare manager, agent, product, and sector performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (where used)
- Power Query (where used)
- Data Visualization
- Business Intelligence
- KPI Reporting

## 📈 Key Performance Indicators

| KPI | Value Displayed |
|---|---:|
| Total Revenue | ₹1,00,05,534 |
| Win Rate | 63% |
